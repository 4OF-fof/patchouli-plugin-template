# patchouli-plugin-template

何もしない Patchouli のプラグイン。GitHub のリリースからインストールする流れを確かめるために使う。

## 中身

| ファイル                        | 役目                                                                  |
| ------------------------------- | --------------------------------------------------------------------- |
| `plugin.json`                   | id・名前・版。機能の宣言は空の `screens` だけ                         |
| `ui.ts`                         | 空のモジュールを export するスクリプト                                |
| `patchouli/`                    | SDK（型・ビルドの道具・WIT）。書き換えない                            |
| `.github/workflows/release.yml` | 既定のブランチに新しい版が入ると、タグとリリースを作って zip を付ける |

## リリースの出し方

`plugin.json` の `version` を上げて、既定のブランチに push する。

- `v<version>` のタグがまだなければ、ワークフローがビルドし、そのタグでリリースを作って zip を付ける。あれば何もしない
- 版に `-` を含むもの（`0.2.0-beta.1` など）は、プレリリースとして出す
- `Cargo.toml` を足すと、WASM もビルドする
- タグは手で打たない

## 手元で作る

```bash
npm install
npm run zip   # template-<版>.zip ができる
```

## アプリで入れる

「プラグイン」の「プラグインを追加」に、このリポジトリの URL を入力する。最新のリリースの zip を取得し、権限を確認してからインストールする。
